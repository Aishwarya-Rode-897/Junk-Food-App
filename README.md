# Junk or No

A beginner-friendly Next.js + Tailwind CSS app where users type a food item and the app tells whether it's junk food or not.

## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Run the development server:

```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000).

## How it works

- Enter a food name (example: `chips`, `apple`, `broccoli`).
- The app checks the input against a small built-in list.
- It returns:
  - **Junk food**
  - **Not junk food**
  - **Unknown food** (if not in the list)
